# 스토리지

스토리지를 만들고 컨테이너에 붙이는 방법입니다.

---

## 스토리지 개요

Cluma의 스토리지는 Kubernetes의 영구 보관 단위(PVC) 위에서 동작합니다. 컨테이너를 지워도 안에 담긴 자료는 그대로 남습니다.

---

## 스토리지 목록

위쪽 메뉴에서 **스토리지**를 누르면 우리 그룹의 스토리지가 한 줄씩 보입니다. 위쪽에는 그룹의 **사용량 / 한도 / 남음** 도 같이 표시됩니다.

| 열 | 어떤 값 |
|----|---------|
| 이름 | 누르면 상세 화면 |
| 상태 | 활성 / 보관 / 삭제됨 |
| 사용자 | 만든 사람 |
| 그룹 | 소속 그룹 |
| 작업 | 삭제 |

**이름** 열은 정렬, **상태 / 사용자 / 그룹** 열은 누르면 그 값으로 걸러 볼 수 있는 드롭다운이 뜹니다.

---

## 스토리지 만들기

**스토리지 생성** 버튼을 누르면 생성 화면으로 갑니다.

| 항목 | 어떤 값 |
|------|---------|
| 스토리지 이름 | 영문 · 숫자 · `-` 조합, 50자 이하 |
| 스토리지 용량 | 슬라이더 또는 직접 입력 (GB). 우리 그룹 남은 한도 안에서 |
| 스토리지 유형 | 클러스터에 등록된 유형 (예: nfs-csi) |
| 접근 범위 | 그룹 안 공유 (현재 기본값) |

용량 입력란 아래에 **만들 수 있는 최대 용량**(한도 - 사용 중)이 안내됩니다.

!!!warning 한도를 넘으면 만들 수 없습니다
관리자에게 한도 늘리기를 요청하세요.
!!!

---

## 컨테이너에 붙이기

컨테이너 만들기 Step 2의 **스토리지** 단계에서 고르고, 컨테이너 안 어떤 경로에 둘지 적습니다.

```
스토리지: my-dataset
마운트 경로: /workspace/data
```

한 컨테이너에 여러 스토리지를 동시에 붙일 수 있습니다.

---

## 스토리지 상세 화면

목록에서 이름을 누르면 상세 화면으로 갑니다.

### 기본 정보

| 항목 | 어떤 값 |
|------|---------|
| 스토리지 이름 | 식별용 이름 |
| 상태 | 지금 상태 |
| 스토리지 ID | 내부 식별자 |
| 용량 | 전체 용량 (GB) |
| 스토리지 유형 | 어떤 유형으로 만들었는지 |
| 접근 범위 | group |

**사용량** 막대로 지금 얼마나 차 있는지 한눈에 봅니다.

### 스토리지 기능 탭

| 탭 | 어떤 내용 |
|----|----------|
| 마운트된 컨테이너 | 지금 이 스토리지를 쓰고 있는 컨테이너 목록 |
| 모니터링 | 준비 중 |

---

## 스토리지 지우기

목록의 삭제 아이콘이나 상세 화면의 **스토리지 삭제** 버튼을 누릅니다. 확인 창에서 스토리지 이름을 직접 적어야 삭제가 풀립니다.

!!!danger 안에 있는 모든 자료가 영구적으로 사라집니다
지우기 전에 꼭 필요한 자료는 다른 곳에 옮겨 두세요.

이 스토리지를 쓰고 있는 컨테이너가 있으면 삭제가 거절됩니다. 먼저 그 컨테이너를 정리하거나 마운트를 해제해야 합니다.

이 스토리지를 기억하고 있는 템플릿이 있다면, 그 템플릿은 이후 못 쓰는 상태가 됩니다.
!!!
