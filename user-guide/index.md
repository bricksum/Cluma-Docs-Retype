# 사용자 가이드

Cluma의 일반 사용자가 자주 쓰는 기능을 정리한 섹션입니다.

---

## 이 섹션의 문서

- [컨테이너 관리](./container.md) — 컨테이너 만들기, 접속하기, 상태 확인하기
- [스토리지 관리](./storage.md) — 스토리지 만들고 컨테이너에 붙이기
- [이미지 관리](./image.md) — 사내 이미지 저장소 탐색, 내 이미지 등록

---

## 처음이라면 이 순서로

**1. 스토리지 먼저 만들기**

학습용 데이터, 모델 파일처럼 오래 두어야 할 자료는 스토리지에 보관합니다. 컨테이너를 지워도 자료는 남습니다.

**2. SSH 공개키 등록**

설정 → SSH Key에서 공개키를 등록해 두면, 컨테이너에 비밀번호 없이 들어갈 수 있습니다.

**3. 컨테이너 만들기**

이미지, 인스턴스(CPU · 메모리 · GPU 묶음), 스토리지 마운트를 정해서 만듭니다.

**4. 컨테이너에 들어가기**

상태가 Running이 되면 SSH · Jupyter · VS Code 카드 버튼으로 바로 들어가서 작업을 시작합니다.

---

## 사용량 확인

화면 위쪽 헤더에서 우리 그룹의 CPU · 메모리 · GPU · 스토리지가 얼마나 남았는지 항상 확인할 수 있습니다. 부족하면 관리자에게 한도 늘리기를 요청합니다.
