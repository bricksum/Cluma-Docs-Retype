사용자 가이드

Cluma의 일반 사용자가 자주 쓰는 기능을 정리한 섹션입니다.

이 섹션의 문서

  • 컨테이너 관리 — 컨테이너 만들기, 접속하기, 상태 확인하기
  • 스토리지 관리 — 스토리지 만들고 컨테이너에 붙이기
  • 이미지 관리 — 사내 이미지 저장소 탐색, 내 이미지 등록

처음이라면 이 순서로

1. 스토리지 먼저 만들기 (선택)

학습용 데이터, 모델 파일처럼 오래 두어야 할 자료는 스토리지에 보관합니다. 컨테이너를 지워도 자료는 남습니다. 처음에는 만들지 않고 시작해도 됩니다.

2. 홈 화면에서 노드 카드 누르기

로그인 후 처음 보이는 홈 화면이 곧 클러스터 예약 화면입니다. 컨테이너를 띄울 노드 카드를 누르면 컨테이너 만들기가 시작됩니다.

3. 컨테이너 옵션 정하기

인스턴스(CPU · 메모리 · GPU 묶음) → 기본 정보 → 스토리지 → 운영 옵션 → 템플릿 저장 여부 → 확인 순서로 진행합니다.

4. 컨테이너에 들어가기

상태가 Running이 되면 컨테이너 상세 화면의 접속 카드(VS Code · SSH · Jupyter)로 바로 들어갑니다. 비밀번호를 묻는 도구라면 같은 화면의 SSH 접속 정보 영역에서 자동 발급 비밀번호를 복사해 씁니다.

사용량 확인

홈 화면 위쪽의 요약 카드에서 그룹 가용 GPU 와 클러스터 점유율 을 항상 확인할 수 있습니다. CPU · 메모리 · 스토리지 한도는 인스턴스 고르기 화면과 스토리지 만들기 화면에서 그때그때 보입니다. 부족하면 관리자에게 한도 늘리기를 요청합니다.
