# 사용자 빠른 시작

Cluma를 처음 쓰시는 분은 아래 순서대로 따라가시면 됩니다.

---

## 1. 로그인

관리자에게 받은 계정으로 로그인합니다.

들어온 뒤 화면 위쪽 **그룹 선택** 메뉴에 본인 그룹이 떠 있는지 확인합니다. 비어 있다면 관리자에게 그룹 배정을 부탁합니다.

---

## 2. 홈 화면 살펴보기

로그인 후 처음 보이는 화면이 **클러스터 예약** 화면입니다. 두 가지를 동시에 보여 줍니다.

- **위쪽 요약 카드 4개**: 내 컨테이너 수 / 내가 쓰고 있는 자원 / 우리 그룹의 가용 GPU / 클러스터 점유율
- **아래쪽 노드 목록**: 클러스터 안의 노드들이 카드로 보입니다. 컨테이너를 만들 노드를 여기서 고릅니다.

---

## 3. 스토리지 만들기 (선택)

학습용 데이터셋이나 모델 파일처럼 컨테이너가 사라져도 남겨야 할 자료는 스토리지에 보관합니다.

1. 위쪽 메뉴 → **스토리지** → **스토리지 생성**
2. 이름, 용량(GB), 스토리지 유형을 정하고 만듭니다.

자세한 내용은 [스토리지 관리](/user-guide/storage.md)를 참고합니다.

!!!note 스토리지 없이 시작해도 괜찮습니다
컨테이너 만들기 안에서도 새 스토리지를 만들 수 있습니다. 처음에는 컨테이너부터 만들어 보세요.
!!!

---

## 4. 컨테이너 만들기

컨테이너 만들기는 홈 화면의 **노드 카드를 클릭하는 것** 으로만 시작합니다. 위쪽 메뉴의 "컨테이너" 페이지에는 만들기 버튼이 없습니다.

노드를 누르면 **컨테이너 시작** 창이 열립니다. 들어가는 길이 두 가지입니다.

### 4-A. 템플릿으로 시작 (가장 빠른 길)

저장된 템플릿이 있으면 창 위쪽에 카드로 보입니다.

1. 원하는 카드를 누릅니다.
2. 확인 창에서 컨테이너 이름을 적습니다.
3. **생성** 버튼을 누르면 바로 만들어집니다.

이미지 · 인스턴스 · 환경 변수 · 스토리지 마운트 · 공유 메모리 설정이 템플릿에서 그대로 옮겨집니다.

### 4-B. 새로 시작 (직접 고르기)

템플릿이 없거나 다른 설정이 필요하면 **또는 새로 시작** 영역에서 인스턴스를 직접 고릅니다.

**Step 1 — 인스턴스 고르기**

CPU · 메모리 · GPU 묶음에서 하나를 골라 **다음**을 누릅니다. 그 자원이 본인 앞으로 **5분간 잠시 잡혀** 있습니다. 그 시간 안에 Step 2를 끝내야 합니다.

**Step 2 — 5단계 옵션 설정**

| 단계 | 무엇을 |
|------|--------|
| 기본 정보 | 컨테이너 이름, 베이스 이미지 |
| 스토리지 | 마운트할 스토리지 (선택) |
| 운영 옵션 | 사용 시간, 공유 메모리, 환경 변수, NUMA 옵션 |
| 템플릿 | 이 설정을 템플릿으로도 저장할지 (선택) |
| 확인 | 설정 다시 보기 → **생성** |

!!!note 접속 포트는 알아서 열립니다
VS Code(8443) · SSH(22) · JupyterLab(8888) 포트가 자동으로 준비됩니다. 사용자가 설정할 게 없습니다.
!!!

!!!note 비밀번호도 자동으로 받습니다
컨테이너마다 비밀번호가 자동으로 만들어집니다. SSH · VS Code · Jupyter 모두 이 한 비밀번호로 들어갑니다. 상세 화면에서 확인할 수 있습니다.
!!!

!!!warning GPU 노드에 CPU만 쓰는 인스턴스는 만들 수 없습니다
가속기가 달린 노드에는 GPU를 1개 이상 할당해야 합니다. CPU만 필요하다면 CPU 전용 노드를 쓰거나, GPU 인스턴스를 받아서 컨테이너 안에서 자유롭게 CPU만 써도 됩니다.
!!!

## 5. 컨테이너에 접속하기

상태가 **Running**이 되면 컨테이너 상세 화면에서 바로 들어갈 수 있습니다.

위쪽에 **접속 카드 세 개**가 보입니다.

| 카드 | 어떻게 동작 |
|------|------------|
| **VS Code** | 브라우저로 code-server를 엽니다. 없으면 PC에 설치된 VS Code가 SSH로 붙도록 폴백합니다. |
| **SSH** | PC의 터미널 앱을 띄우고 SSH 명령어를 클립보드에도 복사해 둡니다. |
| **Jupyter** | 브라우저로 JupyterLab을 엽니다. |

비밀번호를 묻는 도구라면 상세 화면의 **SSH 접속 정보** 영역에서 자동 발급된 비밀번호를 복사해 씁니다.
