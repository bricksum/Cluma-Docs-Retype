# 사전 요구사항

Cluma를 설치하기 전에 클러스터와 작업 PC가 아래 조건을 갖추고 있는지 확인합니다.

---

## 클러스터

### Kubernetes

| 항목 | 조건 |
|------|------|
| Kubernetes 버전 | 1.29 이상 |
| 권한 | 클러스터 전체 관리자 권한 |
| 노드 구성 | 제어 노드 1대 이상 + 작업 노드 1대 이상 |
| GPU 노드 | NVIDIA GPU가 실제로 인식되는 작업 노드 최소 1대 |

### 필요한 부속 요소

**스토리지 유형이 등록되어 있어야 합니다**

사용자 데이터를 저장할 영구 저장소가 클러스터에 미리 준비되어 있어야 합니다. NFS 또는 Local 기반의 저장소 유형을 권장합니다.

```bash
# 등록된 스토리지 유형 확인
kubectl get storageclass
```

**사내 이미지 저장소**

컨테이너 이미지를 보관할 사설 이미지 저장소가 필요합니다. Harbor 또는 클러스터 내부 저장소를 쓸 수 있습니다.

```bash
# 저장소 접속 확인
docker login <저장소 주소>
```

**NVIDIA 드라이버**

GPU 노드에 NVIDIA 드라이버가 설치되어 있어야 합니다.

```bash
# 드라이버 확인
nvidia-smi
```

---

## 작업 PC

Cluma를 설치하고 운영하는 분이 로컬에 갖춰야 할 도구입니다.

| 도구 | 버전 | 용도 |
|------|------|------|
| `kubectl` | 1.29 이상 | 클러스터 관리 |
| `helm` | 3.0 이상 | Helm 차트로 Cluma 설치 |
| `docker` | 20.0 이상 | 이미지 빌드 |

### 설치 확인

```bash
kubectl version --client
helm version
```

---

## 네트워크

- 클러스터 노드끼리 내부 통신이 막혀 있지 않아야 합니다.
- 제어 노드와 작업 노드 사이에 포트 제한이 없어야 합니다.
- 작업 노드에서 사내 이미지 저장소에 접근할 수 있어야 합니다.
