# 관리자 초기 설정

Cluma를 처음 켠 뒤 관리자가 차례대로 해 줘야 할 작업입니다.

---

## 1단계 — 그룹 만들고 한도 정하기

사용자들이 쓸 그룹을 먼저 만들고, 그룹마다 자원의 상한선을 정해 둡니다. 사용자는 그 한도 안에서만 컨테이너와 스토리지를 만들 수 있습니다.

1. 관리자 메뉴 → **그룹 관리** → **그룹 생성**
2. 그룹 이름을 적고 한도를 정합니다.

| 항목 | 어떤 값 |
|------|---------|
| CPU | 그룹 전체가 합쳐서 쓸 수 있는 최대 코어 수 |
| 메모리 | 그룹 전체 최대 메모리 (GB) |
| 가속기 | 가속기 종류별 최대 개수 |
| 스토리지 | 그룹 전체 최대 스토리지 용량 (GB) |

자세한 내용은 [그룹 관리](/admin-guide/group-management.md)에서 확인합니다.

---

## 2단계 — 사용자 만들고 그룹에 넣기

사용자 계정을 만들고 그룹에 넣어 줍니다.

1. 관리자 메뉴 → **사용자 관리** → **사용자 추가하기**
2. 이름, 이메일, 비밀번호, 역할을 적습니다.
3. 만든 사용자의 상세 화면에서 그룹을 추가합니다.

자세한 내용은 [사용자 관리](/admin-guide/user-management.md)에서 확인합니다.

---

## 3단계 — 이미지 저장소 등록 (선택)

사용자가 컨테이너를 만들 때 고를 수 있도록 사내 이미지 저장소를 등록해 둡니다. 등록하지 않으면 사용자는 외부 공개 이미지 주소를 직접 입력해야 합니다.

1. 관리자 메뉴 → **레포지토리 관리** → **+ 등록하기**
2. 이름과 저장소 주소를 적습니다.

자세한 내용은 [레포지토리 관리](/admin-guide/registry-management.md)에서 확인합니다.

---

## 4단계 — 클러스터 상태 살피기

노드와 자원이 잘 잡혔는지 확인합니다.

- 관리자 메뉴 → **클러스터**: 노드 상태(정상 / 작업 배치 제외), Pod 현황
- 관리자 메뉴 → **관리자 대시보드**: 클러스터 전체 CPU · 메모리 · GPU · 스토리지 사용 현황

---

## 끝

여기까지 끝나면 사용자들이 [사용자 빠른 시작](./quickstart.md)을 따라 컨테이너를 만들 수 있습니다.
