# 시작하기

Cluma를 처음 만나는 분을 위한 안내입니다.

---

## 먼저 용어부터

다른 문서에서 모르는 단어가 나오면 항상 [핵심 개념](./concepts.md) 페이지로 돌아오면 됩니다. Cluma에서 쓰는 모든 용어가 한 자리에 정리되어 있습니다.

→ [핵심 개념](./concepts.md)

---

## 역할별 안내

### 일반 사용자

자기 그룹에 배정된 자원 안에서 컨테이너를 만들고 GPU 환경을 씁니다.

→ [사용자 빠른 시작](./quickstart.md)

### 관리자

유저를 만들고 그룹에 자원 한도를 정해 둡니다. 이미지 저장소도 등록합니다.

→ [관리자 초기 설정](./admin-setup.md)
