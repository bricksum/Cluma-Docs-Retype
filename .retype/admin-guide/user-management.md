# 사용자 관리

사용자를 만들고 · 고치고 · 지우고, 역할을 정하는 방법입니다.

---

## 사용자 목록

관리자 메뉴 → **사용자 관리**에서 전체 사용자가 보입니다.

| 열 | 어떤 값 |
|----|---------|
| 이메일 | 로그인할 때 쓰는 주소 |
| 이름 | 화면에 보일 이름 |
| 역할 | 관리자 또는 사용자 |
| 그룹 | 어디에 속해 있는지 |
| 작업 | 고치기(연필) / 지우기(휴지통) |

---

## 사용자 만들기

오른쪽 위 **사용자 추가하기** 를 누릅니다.

| 항목 | 어떤 값 | 필수 |
|------|---------|------|
| 이름 | 화면에 보일 이름 | 필수 |
| 이메일 | 로그인할 주소 | 필수 |
| 비밀번호 | 처음 비밀번호 | 필수 |
| 역할 | 관리자 / 사용자 | 필수 |
| 그룹 | 어디에 넣을지 (여러 곳 가능) | 선택 |

그룹을 안 정하면 자동으로 **Default 그룹**에 들어갑니다.

만든 뒤에는 사용자 상세 화면의 **초기 비밀번호 카드**에서 비밀번호를 다시 확인할 수 있어, 사용자에게 그대로 전달하기 좋습니다.

---

## 사용자 고치기

목록에서 해당 사용자의 **연필 아이콘**을 누릅니다.

이름, 역할, 그룹을 고칠 수 있습니다. **비밀번호 초기화** 버튼으로 그 사용자의 비밀번호를 새로 정할 수 있습니다.

---

## 사용자 지우기

목록에서 **휴지통 아이콘**을 누릅니다. 확인 창에서 사용자 이름을 직접 다시 적어야 삭제가 풀립니다.

!!!danger 되돌릴 수 없습니다
지우면 그 사용자의 컨테이너와 개인 스토리지도 같이 정리될 수 있습니다.
!!!

---

## 활동 이력 살피기

사용자 상세 화면의 **활동 이력 카드**에는 그 사용자의 최근 동작(로그인 · 컨테이너 생성 · 스토리지 생성 등)이 모입니다. 시스템 전체 이력은 [감사 로그](./audit-logs.md) 에서 봅니다.

---

## 누가 무엇을 할 수 있는지

| 기능 | 관리자 | 일반 사용자 |
|------|:------:|:----------:|
| 사용자 만들기 / 고치기 / 지우기 | O | X |
| 그룹 만들기 / 고치기 / 지우기 | O | X |
| 사용자-그룹 넣고 빼기 | O | X |
| 자원 한도 정하기 | O | X |
| 노드 관리 (등록 · 작업 배치 제외) | O | X |
| 이미지 저장소 관리 | O | X |
| 관리자 대시보드 | O | X |
| 감사 로그 조회 | O | X |
| 컨테이너 만들기 / 관리 | O | O (자기 그룹 안에서) |
| 스토리지 만들기 / 관리 | O | O (자기 그룹 안에서) |
| 내 화면(개인 대시보드) | O | O |
| 내 이미지 등록 | O | O |
