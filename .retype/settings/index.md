# 설정

내 프로필과 비밀번호를 관리합니다.

**들어가는 길**: 우상단 사용자 메뉴(프로필 아이콘) → **설정**

---

## 프로필

이름과 이메일을 보고 고칠 수 있습니다.

| 항목 | 어떤 값 |
|------|---------|
| 이름 | 화면에 보일 이름 |
| 이메일 | 계정 이메일 |
| 소속 그룹 | 지금 속해 있는 그룹 목록 (직접 못 바꿉니다 — 관리자에게 요청) |

여러 그룹에 속해 있다면, 화면 위쪽 **그룹 선택** 메뉴에서 지금 활성으로 쓸 그룹을 바꿀 수 있습니다.

---

## 비밀번호 변경

현재 비밀번호와 새 비밀번호(두 칸 확인)를 적고 **비밀번호 변경** 버튼을 누릅니다.

!!!note Cluma 로그인 비밀번호 ≠ 컨테이너 접속 비밀번호
- 이 화면의 비밀번호는 **Cluma 웹 로그인용**입니다.
- 컨테이너에 SSH · VS Code · Jupyter로 접속할 때 쓰는 비밀번호는 **컨테이너마다 자동으로 만들어지는 24자 공통 비밀번호** 입니다. 컨테이너 상세 화면의 SSH 접속 정보 영역에서 확인하세요.
!!!

---

## SSH Key 관리 (현재 비활성)

SSH 공개키 등록 기능은 v1.1에서 일시적으로 숨겨져 있습니다. 그 동안에는 컨테이너마다 자동 발급되는 **24자 공통 비밀번호**로 SSH · VS Code · Jupyter에 접속합니다.

비밀번호는 컨테이너 상세 화면의 **SSH 접속 정보** 영역에서 복사할 수 있습니다.
