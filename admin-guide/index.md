# 관리자 가이드

관리자만 쓸 수 있는 운영 기능을 모아 놓은 섹션입니다. 일반 사용자 화면에서는 이 메뉴가 보이지 않습니다.

---

## 관리자란?

플랫폼 전체를 운영하는 사람입니다. 어떤 그룹에 속하지 않아도 모든 자원과 설정에 접근할 수 있습니다.

---

## 어떤 기능이 있나요

| 기능 | 어떤 일 |
|------|--------|
| 관리자 대시보드 | 전체 사용량 · 그룹별 사용량을 한눈에 |
| 사용자 관리 | 사용자 만들고 · 고치고 · 지우기, 역할 정하기 |
| 그룹 관리 | 그룹 만들고 · 자원 한도 정하기, 사용자 넣고 빼기 |
| 레포지토리 관리 | 사내 이미지 저장소 등록 |
| 클러스터 | 노드 · 분포 · 사용량 · 모니터링 · 스토리지 다섯 탭을 한 화면에 |
| 감사 로그 | 누가 무엇을 했는지 이력 조회 |

---
