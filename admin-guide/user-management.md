# 사용자 관리

사용자 생성·수정·삭제 및 역할 설정 방법을 설명합니다.

---

## 사용자 목록

관리자 메뉴 → **사용자 관리**에서 전체 사용자 목록을 확인할 수 있습니다.

| 컬럼 | 설명 |
|------|------|
| 이메일 | 로그인에 사용하는 이메일 주소 |
| 이름 | 사용자 표시 이름 |
| 역할 | 관리자 또는 사용자 |
| 그룹 | 소속된 그룹 목록 |
| 작업 | 수정(연필 아이콘) / 삭제(휴지통 아이콘) |

---

## 사용자 생성

우측 상단 **사용자 추가하기** 버튼을 클릭합니다.

| 항목 | 설명 | 필수 |
|------|------|------|
| 이름 | 사용자 표시 이름 | 필수 |
| 이메일 | 로그인에 사용할 이메일 주소 | 필수 |
| 비밀번호 | 초기 비밀번호 | 필수 |
| 역할 | 관리자 또는 사용자 | 필수 |
| 그룹 | 소속 그룹 (여러 개 선택 가능) | 선택 |

생성 시 그룹을 지정하지 않으면 **Default 그룹**에 자동 배정됩니다.

생성 후 사용자 상세 페이지의 **초기 비밀번호 카드**에서 초기 비밀번호를 다시 확인할 수 있습니다 (관리자가 사용자에게 안내용).

---

## 사용자 수정

목록에서 수정할 사용자의 **연필 아이콘**을 클릭합니다.

이름, 역할, 그룹을 수정할 수 있습니다. **비밀번호 초기화** 버튼으로 해당 사용자의 비밀번호를 초기화할 수 있습니다.

---

## 사용자 삭제

목록에서 삭제할 사용자의 **휴지통 아이콘**을 클릭합니다. 삭제 확인을 위해 **사용자 이름을 직접 입력**해야 합니다.

!!!danger 삭제 시 주의
이 작업은 되돌릴 수 없습니다. 사용자를 삭제하면 해당 사용자의 컨테이너와 개인 스토리지가 함께 삭제될 수 있습니다.
!!!

---

## 사용자 활동 이력

사용자 상세 페이지의 **활동 이력 카드**에서 해당 사용자의 최근 동작(로그인 · 컨테이너 생성 · 스토리지 생성 등)을 조회할 수 있습니다. 전체 시스템 이력은 [감사 로그](./audit-logs.md)에서 조회합니다.

---

## 역할 기반 접근 제어

| 기능 | 관리자 | 일반 사용자 |
|------|:------:|:----------:|
| 사용자 생성/수정/삭제 | O | X |
| 그룹 생성/수정/삭제 | O | X |
| 사용자-그룹 할당/제거 | O | X |
| 리소스 한도 설정 | O | X |
| 노드 관리 (등록/스케줄러 제외) | O | X |
| 레포지토리 관리 | O | X |
| 관리자 대시보드 | O | X |
| 감사 로그 조회 | O | X |
| 컨테이너 생성/관리 | O | O (소속 그룹 내) |
| 스토리지 생성/관리 | O | O (소속 그룹 내) |
| 개인 대시보드 | O | O |
| 커스텀 이미지 등록 | O | O |
