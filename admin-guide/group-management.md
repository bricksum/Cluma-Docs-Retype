# 그룹 관리

그룹을 만들고 자원 한도를 정하는 방법입니다.

---

## 개요

그룹은 사용자들을 묶고 같이 쓸 자원의 상한선을 정해 두는 단위입니다. 사용자는 어느 그룹에든 한 곳 이상 속해야 컨테이너와 스토리지를 만들 수 있습니다.

---

## 그룹 목록

관리자 메뉴 → **그룹 관리**에서 전체 그룹이 보입니다.

| 열 | 어떤 값 |
|----|---------|
| 그룹명 | 그룹 이름 |
| CPU | 정해 둔 CPU 코어 |
| 메모리(GB) | 정해 둔 메모리 |
| 가속기 | 정해 둔 GPU 등 가속기 수 |
| 스토리지(GB) | 정해 둔 스토리지 용량 |
| 멤버수 | 속한 사용자 수 |
| 작업 | 고치기(연필) / 지우기(휴지통) |

---

## 그룹 만들기

오른쪽 위 **그룹 추가하기** 를 누릅니다.

### 이름

알아볼 수 있는 이름을 적습니다 (예: 개발팀, 연구팀).

### 자원 한도

위쪽에 **지금 클러스터에 남아 있는 자원** 이 실시간으로 보이므로, 그걸 보면서 정합니다.

| 항목 | 단위 |
|------|------|
| CPU 코어 | 2의 배수 |
| 메모리 | 2의 거듭제곱 (2, 4, 8, 16, 32 GB ...) |
| 스토리지 | 10GB 단위 또는 직접 입력 |

### 가속기 한도

등록된 가속기 종류별(NVIDIA GPU 등)로 몇 개까지 줄지 정합니다. 카드에 **줄 수 있는 수 / 전체 수**가 함께 나옵니다.

### 한도 적용 후 남는 자원

아래쪽 **한도 적용 후 남는 자원** 영역에서, 이 그룹에 주고 나면 클러스터에 얼마가 남는지 미리 보여 줍니다.

```
보기) Default 그룹 한도
├── CPU: 20 코어
├── 메모리: 64 GB
├── 스토리지: 90 GB
└── NVIDIA GPU: 1 개

→ A가 GPU 1개를 쓰고 있으면, B는 GPU를 더 못 씁니다.
```

!!!warning 한도가 너무 낮으면
사용자가 컨테이너를 못 만듭니다. 대시보드에서 그룹의 남은 자원을 보면서 적당히 조절하세요.
!!!

---

## 그룹 고치기

목록에서 해당 그룹의 **연필 아이콘**을 누릅니다.

이름과 자원 한도(CPU · 메모리 · 스토리지 · 가속기)를 고칠 수 있습니다. 고치는 동안에도 클러스터 남은 자원과 한도 적용 후 남는 자원이 실시간으로 보입니다.

!!!warning 지금 쓰는 양보다 낮게 줄이면
이미 동작 중인 컨테이너는 그대로 두지만, 새 컨테이너는 못 만들게 됩니다.
!!!

---

## 그룹 지우기

목록에서 **휴지통 아이콘**을 누릅니다. 확인 창에서 그룹 이름을 직접 적어야 삭제가 풀립니다.

!!!danger 그룹 안 모든 것이 함께 사라집니다
지우면 그 그룹에 속한 컨테이너와 스토리지가 모두 영구적으로 없어집니다.
!!!

---

## 사용자를 그룹에 넣고 빼기

### 그룹에 넣기

사용자를 만들 때 그룹을 정하거나, 관리자 메뉴 → **사용자 관리** → 사용자 고치기에서 그룹을 추가합니다.

- 한 사용자는 여러 그룹에 동시에 속할 수 있습니다.
- 여러 곳에 속해 있으면, 컨테이너를 만들 때 어느 그룹으로 만들지 고릅니다.

### 그룹에서 빼기

사용자 고치기 화면에서 그룹을 빼면 됩니다. 단, 모든 그룹에서 빠지면 자원을 못 쓰므로 최소 한 곳에는 속하도록 두기를 권장합니다.
