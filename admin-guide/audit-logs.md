# 감사 로그

플랫폼의 모든 주요 동작이 기록되는 감사 로그를 조회하고 분석합니다.

관리자 메뉴 → **감사 로그**에서 접근합니다.

---

## 기록되는 동작

| 카테고리 | 예시 |
|---------|------|
| 인증 (auth) | 로그인, 로그아웃, 토큰 갱신 |
| 컨테이너 (container) | 생성, 수정, 삭제, 예약, Pod 진단 조회 |
| 스토리지 (storage) | 생성, 수정, 삭제, 마운트 |
| 사용자 (user) | 생성, 수정, 삭제, 비밀번호 초기화 |
| 그룹 (group) | 생성, 수정, 삭제, 멤버 변경 |
| 템플릿 (template) | 생성, 삭제 |
| 레포지토리 (repository) | 등록, 수정, 삭제 |

각 이벤트에는 사용자 · 액션 · 결과(success/failure) · HTTP 상태 코드 · 소요 시간 · 리소스 식별자 · IP 주소 · 요청 ID 가 함께 기록됩니다.

---

## 필터

상단의 필터 패널에서 조회 범위를 좁힐 수 있습니다.

| 필터 | 설명 |
|------|------|
| 시작일 / 종료일 | `datetime-local` 입력 (분 단위) |
| 사용자 | 이메일로 필터링 |
| 카테고리 | 전체 / 인증 / 컨테이너 / 스토리지 / 사용자 / 그룹 / 템플릿 / 레포지토리 |
| 결과 | 전체 / 성공 / 실패 |
| 액션 | 액션 키워드 검색 (예: `container.create`) |

필터 변경 후 **적용** 버튼을 누르면 결과가 갱신됩니다. **초기화** 버튼으로 전체 조회로 복귀합니다.

---

## 로그 테이블

| 컬럼 | 설명 |
|------|------|
| 시간 | 이벤트 발생 시각 (`YYYY-MM-DD HH:MM:SS`) |
| 사용자 | 동작을 수행한 사용자 이메일 |
| 액션 | 액션 코드 (예: `container.create`, `auth.login`) |
| 카테고리 | 인증 / 컨테이너 / ... |
| 결과 | 성공 / 실패 |
| 리소스 | 영향받은 리소스 (`type:name` 형식) |
| 상태코드 | HTTP 응답 코드 |
| 소요시간 | 요청 처리 시간 (ms / s) |

행을 클릭하면 **상세 모달**이 열립니다.

---

## 상세 모달

행을 클릭하면 다음 정보가 표시됩니다.

| 항목 | 설명 |
|------|------|
| 기본 정보 | 시간 · 사용자 · 액션 · 카테고리 · 결과 |
| 요청 정보 | HTTP 메서드 · 경로 · 상태 코드 · IP 주소 · Request ID |
| 리소스 | 영향받은 리소스의 type / id / name |
| Details | 액션별 추가 정보 (JSON) — 예: 컨테이너 생성 시 인스턴스 ID, 이미지 등 |

Request ID는 backend 로그와 1:1로 매칭되므로, 실패 원인 추적 시 backend 로그에서 같은 ID를 검색하면 됩니다.

---

## 페이지네이션

테이블 하단에서 페이지를 이동합니다. 기본 50개씩 표시되며, 필터를 좁히면 응답이 빨라집니다.

---

## 활용 예시

| 상황 | 조회 방법 |
|------|----------|
| 특정 사용자의 동작 추적 | 사용자 필터 + 시간 범위 |
| 실패한 컨테이너 생성 원인 분석 | 카테고리=container, 결과=실패 |
| 비정상 로그인 시도 감지 | 카테고리=auth, 결과=실패 |
| 누가 그룹을 삭제했는지 확인 | 액션=`group.delete` |
