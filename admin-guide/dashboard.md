# 관리자 대시보드

전체 클러스터와 그룹별 사용 현황을 한눈에 살펴보는 화면입니다.

관리자 메뉴 → **관리자 대시보드** 로 들어갑니다.

---

## 위쪽 — 클러스터 전체 현황

자원별로 카드가 보입니다. 각 카드에는 **사용량 / 한도 / 총량** 과 사용률 막대가 함께 들어 있습니다.

| 카드 | 단위 |
|------|------|
| CPU | 코어 |
| Memory | GB |
| Storage | GB |
| 가속기 | 종류별로 카드 한 장씩 (개) |

사용률에 따라 색이 바뀝니다.

| 범위 | 색 |
|------|-----|
| 0 ~ 69% | 기본 |
| 70 ~ 89% | 노랑 |
| 90% 이상 | 빨강 |

---

## 아래쪽 — 그룹별 사용량

### 그룹 고르기

위쪽 드롭다운에서 그룹을 고르면 파이 차트가 다르게 보입니다.

| 고른 값 | 파이 차트가 보여주는 것 |
|---------|----------------------|
| 전체 | 클러스터 전체 용량에서 그룹들이 차지하는 비율 |
| 특정 그룹 | 그 그룹의 한도 안에서 지금 얼마나 쓰고 있는지 |

파이 차트의 그룹 영역을 직접 눌러도 같은 효과입니다. **← 전체 보기** 버튼으로 다시 돌아옵니다.

차트에 마우스를 올리면 그 그룹의 한도와 비율이 풍선 도움말로 나옵니다.

### 파이 차트

CPU · Memory · 가속기 · Storage 네 가지에 대해, 그룹별로 어떻게 나뉘는지 보여 줍니다. 아무한테도 안 준 영역은 회색입니다.

### 그룹별 표

모든 그룹의 사용 현황이 한 표에 모입니다.

| 열 | 어떤 값 |
|----|---------|
| 그룹명 | 누르면 그 그룹만 따로 보기 |
| CPU 사용/한도 | 사용량 / 한도 / 사용률(%) |
| MEMORY 사용/한도 | 메모리(GB) 사용량 / 한도 / 사용률(%) |
| 가속기 사용/한도 | 가속기 종류별 사용량 / 한도 |
| STORAGE 사용/한도 | 스토리지(GB) 사용량 / 한도 / 사용률(%) |
| POD 수 | 지금 동작 중인 Pod 수 |

사용률이 70%를 넘으면 노랑, 90%를 넘으면 빨강으로 강조됩니다. 한도가 정해져 있지 않으면 `(미할당)` 으로 보입니다.
