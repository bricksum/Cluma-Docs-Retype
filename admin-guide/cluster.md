# 클러스터

클러스터 노드 상태, 자원 분포, 사용량 추이, 외부 모니터링, 스토리지 현황을 통합 조회하는 화면입니다.

관리자 메뉴 → **클러스터**에서 접근합니다. 단일 페이지 안에 5개 탭으로 구성됩니다.

---

## 페이지 구성

| 탭 | 설명 |
|------|------|
| 상태 (Status) | 노드 목록 · 진단 · 스케줄러 제외 |
| 분포 (Distribution) | 가속기 시각화, 그룹/Pod별 점유 시각화 |
| 사용량 (Usage) | CPU · 메모리 · 가속기 사용률 카드 |
| 모니터링 (Monitoring) | Grafana 대시보드 외부 연동 |
| 스토리지 (Storage) | StorageClass별 용량 · 사용량 |

상단의 **마지막 업데이트 / 자동 새로고침 / 새로고침** 컨트롤은 모든 탭에 공통 적용됩니다.

---

## 상태 (Status) 탭

### 요약 카드

| 카드 | 설명 |
|------|------|
| Ready 노드 | 정상 동작 중인 노드 수 |
| Drained 노드 | 스케줄러에서 제외된 노드 수 |
| 전체 Pod | 클러스터의 전체 Pod 수 |
| 실행 중 Pod | 정상 실행 중인 Pod 수 |
| Pending Pod | 대기 중인 Pod 수 |

### 노드 목록

요약 카드 하단에 **Ready 노드**와 **Drained 노드** 섹션이 구분되어 표시됩니다.

**뷰 모드 (그리드 / 리스트)**

| 모드 | 설명 |
|------|------|
| 그리드 | 노드를 카드 형태로 표시. 가속기 시각화 포함 |
| 리스트 | 노드를 행 형태로 표시. 많은 노드 일람용 |

**디바이스 필터**

| 옵션 | 설명 |
|------|------|
| 전체 디바이스 | 모든 노드 표시 |
| 특정 가속기 | 해당 가속기를 보유한 노드만 표시 (예: NVIDIA A100) |

### 노드 상세 모달

노드 카드(그리드) 또는 행(리스트)을 클릭하면 상세 모달이 열립니다.

**노드 스펙**

| 항목 | 설명 |
|------|------|
| 상태 배지 | Ready / NotReady / SchedulingDisabled |
| 역할 배지 | Control Plane / Data Plane |
| CPU | 탑재된 CPU 코어 수 |
| 메모리 | 탑재된 메모리 (GB) |
| 가속기 | 종류 및 수량 |
| 스토리지 | 탑재된 스토리지 (GB) |

**실행 중인 Pods**: 해당 노드에서 실행 중인 Pod 목록.

**노드 진단**

| 진단 항목 | 의미 |
|-----------|------|
| NetworkUnavailable | 네트워크 불가, CNI 플러그인 문제 등 |
| MemoryPressure | 메모리 부족, OOM 발생 가능성 |
| DiskPressure | 디스크 부족, 사용량이 임계값 초과 |
| PIDPressure | 프로세스 수 제한 도달 |

정상이면 녹색, 문제가 있으면 경고로 표시됩니다.

!!!warning 진단 항목 이상 시
새로운 Pod 스케줄링이 차단되거나 기존 Pod가 불안정해질 수 있습니다. 즉시 원인을 파악하고 조치하세요.
!!!

**스케줄러 제외 (Drain)**

모달 하단의 **스케줄러 제외** 버튼으로 노드를 Drained 상태로 전환합니다.

- Drained 상태의 노드에는 새로운 Pod가 배치되지 않습니다.
- 기존 Pod는 계속 동작합니다.
- 하드웨어 유지보수 / 드라이버 업데이트 / 노드 점검에 활용합니다.

---

## 분포 (Distribution) 탭

가속기 자원의 점유 현황을 시각화합니다.

| 모드 | 설명 |
|------|------|
| 사용유무 | 사용 / 미사용 단순 표시 |
| Pod별 구분 | 각 가속기 슬롯이 어떤 Pod에 할당됐는지 표시 |
| 그룹별 구분 | 그룹별 가속기 사용 현황 (그룹 범례 표시) |

그룹 색상 범례를 통해 어느 그룹이 어느 GPU를 점유 중인지 빠르게 파악할 수 있습니다.

---

## 사용량 (Usage) 탭

클러스터 전체 자원 사용률을 카드와 막대 그래프로 표시합니다.

| 카드 | 단위 |
|------|------|
| CPU | cores |
| Memory | GB |
| 가속기 유형별 | 개수 |
| Storage | GB |

각 카드에는 **사용량 / 할당량 / 총량** 및 사용률 막대가 표시됩니다.

| 범위 | 색상 |
|------|------|
| 0 ~ 69% | 기본 |
| 70 ~ 89% | 노란색 |
| 90% 이상 | 빨간색 |

---

## 모니터링 (Monitoring) 탭

Grafana 대시보드로 시계열 그래프를 확인합니다. 클러스터 페이지의 **모니터링** 탭을 클릭하면 Grafana가 새 탭으로 열립니다.

Grafana는 Cluma와 별도로 Kubernetes 클러스터 내 `monitoring` 네임스페이스에 배포되며, Cluma 관리자가 해당 URL을 환경변수로 설정한 경우에만 접근할 수 있습니다.

!!!note 탭 클릭 시 아무 반응이 없는 경우
Grafana URL이 설정되지 않은 상태입니다. 클러스터 배포 담당자에게 frontend 빌드의 `NEXT_PUBLIC_GRAFANA_URL` 환경변수 설정을 요청하세요.
!!!

### Grafana에서 확인할 수 있는 정보

| 항목 | 설명 |
|------|------|
| CPU 사용률 | 노드별·전체 CPU 사용률 추이 |
| 메모리 사용률 | 노드별·전체 메모리 사용률 추이 |
| GPU 사용률 | GPU 노드의 가속기 사용률 추이 (DCGM 기반) |
| 네트워크 I/O | 노드별 네트워크 입출력 트래픽 |
| 디스크 I/O | 노드별 디스크 읽기/쓰기 |
| Pod 상태 | 네임스페이스별 Pod 수 및 상태 추이 |

### Grafana 접속 정보

| 항목 | 기본값 |
|------|--------|
| Grafana 주소 | `http://grafana.internal` |
| 네임스페이스 | `monitoring` |

!!!note 내부 도메인 접근 설정
`grafana.internal` 등 내부 도메인을 사용하는 경우, 클라이언트 PC의 `/etc/hosts` 파일에 아래 항목을 추가해야 합니다.

```
<노드 IP>  grafana.internal
```
!!!

## 스토리지 (Storage) 탭

클러스터에 등록된 StorageClass별 용량과 사용량을 확인합니다.

| 항목 | 설명 |
|------|------|
| StorageClass | NFS / Local 등 |
| 전체 용량 | 클러스터가 인식한 총 용량 |
| 사용량 | 현재 PVC가 점유한 용량 |
| 사용률 | 백분율 (70% 노랑 / 90% 빨강) |

---

## 클러스터 자원 측정 vs 시계열 분석

| 비교 | 사용량 탭 | 모니터링 탭 |
|---|---|---|
| 목적 | 현재 점유율 확인 | 사용량 시계열 추이 분석 |
| 데이터 | 현재 상태 스냅샷 | 과거~현재 그래프 |
| 도구 | Cluma 내장 | Grafana (외부 연동) |
