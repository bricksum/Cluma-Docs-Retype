# 설정

프로필 정보, 비밀번호, SSH Key를 관리합니다.

**진입**: 우상단 사용자 메뉴(프로필 아이콘) → **설정**

---

## 프로필 정보

이름과 이메일을 확인하고 수정할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 이름 | 플랫폼 내 표시 이름 |
| 이메일 | 계정 이메일 주소 |
| 소속 그룹 | 현재 소속된 그룹 (변경 불가, 관리자에게 요청) |

그룹은 헤더 상단의 **그룹 선택** 드롭다운에서 활성 그룹을 전환할 수 있습니다 (여러 그룹에 소속된 경우).

---

## 비밀번호 변경

새 비밀번호를 입력하고 확인란에 동일하게 입력한 뒤 **저장** 버튼을 클릭합니다.

---

## SSH Key 관리

SSH Key를 등록하면 컨테이너에 SSH로 안전하게 접속할 수 있습니다.

### SSH Key 등록

설정 페이지 하단의 **SSH Key 추가** 버튼을 클릭합니다.

| 항목 | 설명 |
|------|------|
| SSH Key 이름 | Key를 식별하는 이름 (예: My Laptop Key) |
| SSH 공개키 | 직접 입력 또는 파일 업로드 |

- **직접 입력**: 공개키 텍스트를 붙여넣습니다. (`ssh-rsa AAAA...` 또는 `ssh-ed25519 AAAA...` 형식)
- **파일 업로드**: `.pub` 파일을 선택하여 업로드합니다.

### SSH Key 사용

컨테이너 생성 모달의 Step 2 → **SSH Key** 영역에서 등록한 Key를 선택하면, 컨테이너 시작 시 공개키가 자동으로 주입됩니다. 비밀번호 없이 Key 기반 SSH 인증을 사용할 수 있습니다.

### SSH Key 삭제

등록된 Key 목록에서 삭제 아이콘을 클릭합니다.

!!!note 삭제 효과
삭제된 SSH Key는 새 컨테이너에는 더 이상 주입되지 않습니다. 이미 실행 중인 컨테이너 안의 `~/.ssh/authorized_keys`는 영향받지 않으므로, 보안상 즉시 차단이 필요하면 해당 컨테이너 안에서 직접 키를 제거하거나 컨테이너를 재생성하세요.
!!!
