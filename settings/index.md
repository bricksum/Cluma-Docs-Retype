# 설정

내 프로필, 비밀번호, SSH Key를 관리합니다.

**들어가는 길**: 우상단 사용자 메뉴(프로필 아이콘) → **설정**

---

## 프로필

이름과 이메일을 보고 고칠 수 있습니다.

| 항목 | 어떤 값 |
|------|---------|
| 이름 | 화면에 보일 이름 |
| 이메일 | 계정 이메일 |
| 소속 그룹 | 지금 속해 있는 그룹 (직접 못 바꿉니다 — 관리자에게 요청) |

여러 그룹에 속해 있다면, 화면 위쪽 **그룹 선택** 메뉴에서 지금 활성으로 쓸 그룹을 바꿀 수 있습니다.

---

## 비밀번호 변경

새 비밀번호를 두 칸에 똑같이 적고 **저장**을 누릅니다.

---

## SSH Key 관리

SSH Key를 등록해 두면 컨테이너에 비밀번호 없이 들어갈 수 있습니다.

### Key 등록

설정 페이지 아래쪽 **SSH Key 추가** 버튼을 누릅니다.

| 항목 | 어떤 값 |
|------|---------|
| SSH Key 이름 | 알아볼 수 있는 이름 (예: My Laptop Key) |
| SSH 공개키 | 직접 입력 또는 파일 업로드 |

- **직접 입력**: `ssh-rsa AAAA...` 또는 `ssh-ed25519 AAAA...` 형식 텍스트를 그대로 붙여 넣습니다.
- **파일 업로드**: `.pub` 파일을 골라서 올립니다.

### Key 쓰는 법

컨테이너 만들기 2단계 → **SSH Key** 영역에서 등록한 키를 고릅니다. 컨테이너가 켜질 때 그 공개키가 안에 자동으로 들어가, 비밀번호 없이 SSH로 들어갈 수 있게 됩니다.

### Key 지우기

등록된 키 목록에서 삭제 아이콘을 누릅니다.

!!!note 지운 뒤에도 이미 떠 있는 컨테이너에는 남아 있을 수 있습니다
새 컨테이너에는 더 이상 그 키가 들어가지 않습니다. 다만 이미 동작 중인 컨테이너 안 `~/.ssh/authorized_keys` 는 그대로 두어, 즉시 차단이 필요하다면 그 컨테이너 안에서 키를 직접 지우거나 컨테이너를 새로 만들어야 합니다.
!!!
