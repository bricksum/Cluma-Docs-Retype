# Release Notes

Cluma의 주요 변경 사항을 날짜순으로 안내합니다. 신규 기능, 사용자 영향이 있는 변경, 보안 강화, 버그 수정을 묶어 발행합니다.

각 항목 페이지에는 사용자 영향 / 신규 기능 / 마이그레이션 노트를 포함합니다.

---

## 최신 변경 사항

| 날짜 | 버전 | 주요 내용 |
|------|------|----------|
| [2026-05-29](./2026-05-29.md) | v1.1.0 | 표준 포트 자동 노출, Pod 진단, 보안 격리, GPU 비례 자원, 인스턴스 카탈로그, 템플릿 마운트만 정책 |

---

## 구독

릴리스 노트는 Cluma 사이드바의 알림 영역(준비 중)으로도 전달될 예정입니다. 그 전까지는 이 페이지를 북마크하여 주기적으로 확인하시기를 권장합니다.
